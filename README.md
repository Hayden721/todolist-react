# 결과 및 성과
1. Oracle Cloud를 활용하여 Spring Boot 애플리케이션을 배포해보며 클라우드 환경에서의 배포 프로세스를 경험할 수 있었습니다.
2. React와 Spring Boot 간의 데이터 통신을 구현하면서 CORS 설정과 REST API 통신 구조에 대한 이해를 높일 수 있었습니다.
